# Roadmap

Priority reflects dependencies and evidence, not delivery promises.

## Before public production distribution

- [ ] Choose a project-wide licence after provenance/rights review; retain component notices.
- [ ] Configure a stable release signing identity and the four GitHub Secrets; test a version-tag release.
- [ ] Complete clean-clone CI and real-device installation acceptance for the published commit.
- [ ] Exercise long outdoor/locked indoor sessions on the Samsung S23 and representative Android 8–16 devices; measure rather than infer sensor accuracy.
- [ ] Obtain qualified review of training rules and clear coaching limitations.
- [ ] Enable private vulnerability reporting and establish a private conduct contact.

## Contributor priorities

- [ ] Capture current device screenshots and improve TalkBack/large-font behaviour.
- [ ] Expand sanitised provider fixtures and network failure/cancellation tests.
- [ ] Improve international location/country filtering and source-conflict presentation.
- [ ] Establish Room migration tests as the catalogue schema evolves.
- [ ] Verify local model compatibility, download flow and resource use across devices.

## Integrations requiring external access

- [ ] RunSignup catalogue caching approval and an operator-provided HTTPS credential proxy.
- [ ] Garmin official partner approval, credentials and independently implemented two-way integration.
- [ ] Live end-to-end Strava/Health Connect/Bluetooth validation with user consent and compatible devices.

Running and walking remain the product focus. No promise of Runna parity, ultra/trail-specific programmes, automatic treadmill control or medical validation is made.
