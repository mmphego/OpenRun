# Original OpenRun listing artwork

play-icon.svg is a vector export of the original OpenRun r mark already used in Android drawables. feature-graphic.svg is original typographic brand artwork, not a screenshot or an illustration of tested functionality. PNG exports use CairoSVG 2.7.1. All artwork remains draft until the publisher reviews the listing and visual presentation.

These files contain no Runna assets, user photos or GPS routes. Edit the vectors for branding changes; recapture actual screenshots from a tested app build for the store.
