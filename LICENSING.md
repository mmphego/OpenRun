# Licensing status

No project-wide OpenRun licence was present in the recovered source, and no verifiable project Git history was available. A new licence has intentionally not been invented or copied from the reference project.

Public visibility alone does not grant a general licence to use, modify or redistribute the OpenRun implementation. The maintainer must select a licence after verifying ownership and provenance before describing the repository as fully open source or accepting contributions under an assumed licence.

Third-party components keep their own licences. Existing notices in `docs/THIRD-PARTY.md`, `docs/icons/LICENSE` and `app/src/main/assets/licenses/` are preserved. External build tools and test dependencies are not relicensed. Gemma weights are not included and require the publisher's terms.

openGym is a presentation/onboarding reference only; its source, assets and AGPL licence have not been imported.
